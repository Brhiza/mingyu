# 时间、历法、应期与动态节点规范（Timing & Dynamic Events）

玄学预测的核心价值之一，在于帮助人们感知时间节律的变化、把握行动窗口。精确的时间处理与分层的应期推算，是保证推演可信度的生命线。

---

## 1. 时间基准与多重历法口径

所有推演必须首先明确并记录以下时间基础信息：
1. **输入当地钟表时间（Local Clock Time）**：如 `1992-08-21 15:30`；
2. **时区标识（Timezone）**：明确 UTC 偏移量（如 `UTC+8`）或 IANA 标准时区（如 `Asia/Shanghai`, `America/New_York`）；
3. **历法体系（Calendar System）**：
   - **公历（Gregorian）**：西方占星与日常民用基准；
   - **农历（Lunar / Yin-Yang Calendar）**：紫微斗数安星基准、小六壬起课基准；
   - **干支历（Sexagenary / Solar Terms）**：八字、奇门、六爻、太乙、大六壬之根本，**以二十四节气（如立春、惊蛰、清明等时刻）交节为月建与年支之唯一交接点**，严禁以正月初一或公历元旦机械换年换月！
4. **真太阳时（True Solar Time）校正**：
   - 包含**经度时差**（每度经度相差 4 分钟）与地球公转轨道偏心率带来的**均时差（Equation of Time）**；
   - 当涉及出生时辰处于两个时辰交界线（如 12:55~13:05）时，真太阳时校正是定盘是否准确的关键决定因素；
   - 中国 1986-1991 年历史夏令时需特别注意减去 1 小时回调。

## 2. 周期型任务的动态节点扫描分辨率

对“未来三年趋势”、“今年运势”或“某人生阶段”进行动态分析时，不得仅列出一个抽象的整体评分或单一吉凶标签，必须建立清晰的时间分辨率节点清单：

| 时间分辨率 | 对应的核心天文与节律事件 | 对应术数的具体动态映射 |
| :--- | :--- | :--- |
| **年级别（Yearly）** | 太岁地支交接、慢行星（土/木/天/海/冥）换座、值年卦换卦 | 八字流年太岁冲合生克、紫微流年命迁官财四化、奇门太岁入局动静 |
| **季度/节气级别（Seasonal）** | 二十四节气交节时刻、五运六气步运气交接、日月食窗口 | 八字节令月建旺衰转换、奇门拆补置闰上中下三元换局、月将值临 |
| **月级别（Monthly）** | 朔望月（新月满月）、内行星逆行/顺行、流月干支运转 | 六爻月建临值、紫微流月四化飞星引动、西占关键相位精确度数成相 |
| **日级别（Daily）** | 流日干支、日辰冲动、月亮过境敏感度数、择日建除十二神 | 六爻日辰暗动与日破、择日避开岁破与月破日、奇门日家值符 |
| **时辰级别（Hourly）** | 起卦时刻时辰、日夜贵人划分、早晚子时交替 | 奇门时家起局、六爻时辰辅助定发端、金口诀时辰定遁干 |

## 3. 应期表达规范（Timing & Windows）

传统应期不是宿命论的“几月几日几分必死或必发财”，而是**“能量场交互最强烈的时空窗口与现实触发条件”**：

1. **应期四阶段模型**：
   - **气机萌发（Window Starts）**：该时空周期的引动因素开始显现，现实中出现端倪或早期接触；
   - **能量峰值（Peak Moment）**：干支冲合、星曜四化叠照或相位精确成相时刻，现实事件进入推进或摊牌的关键高潮；
   - **动荡平复（Window Ends）**：克应力量衰退，事态进入结果消化或常态运转；
   - **反复回溯（Retrograde & Recurrence）**：行星逆行再过境或流年伏吟反吟，提示该议题在过往曾有旧案，需经二次复盘方能彻底解决。
2. **严禁越级断应期**：
   - 若盘面仅具备**年干支**层面的大运太岁依据，结论只能锁定在“某年内（如 2026 年）”；严禁在缺乏月建日辰细化证据时，随口乱编“2026年3月18日下午3点必定发生”。
