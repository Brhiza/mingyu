# 盘面事实与推理核验

用于解读已取得的盘面，或将盘面交给另一个模型。目标是减少影响结论的常见误读，同时控制上下文长度；核验通过表示本次关键事实已对照，不代表模型回答无误。

## 按本次问题取证

保留完整的所选原生任务书，将本文件用于自身工作流程。按所选术数读取下面相关行，不把整份规则表、其他术数资料或审查记录追加给解读模型。用户仅要求原生提示词时，直接交付原生正文。

先绑定三类身份：谁的盘、哪一个时点、采用哪一种方法。双人关系同时保留两端姓名或代称；时间区分出生、本命、当前、目标、运段与精确事件；流派和起卦方式沿用本次实际输入。

对影响主要结论的关系核对两端、方向和条件。已有计算结果优先直接引用，补算通过相应计算工具完成。只有补充资料会改变当前判断时才追问；暂缺的层级保留为空，先完成已有资料支持的部分。

## 输出前的有限复核

核对结论真正依赖的几项盘面事实，并扫一遍总结中重新引用的实体与方向。发现矛盾时回到对应计算或原文修正该处，保留仍成立的部分。对无法验证的引申降低确定度，避免通过继续增加资料或反复重写制造已消除错误的印象。

将计算事实、传统解释和现实建议在含义上区分；内部核验编号与过程留在工作记录中。面向在线 AI 的任务书只保留本次任务、盘面与必要传统依据。

## 改进提示词时

先区分缺少事实、表达歧义、计算错误和模型已读到正确事实仍误推。前三类在对应数据或格式层修正；最后一类优先记录残余风险并改善关键结论复核，不为一次随机错误持续加长正文。

新增事实应能由实际结果确定，并能减少一个已观察到的主要歧义。采用相同盘面和参数做少量前后对照，读到实际断言再评价；接口成功、回答长度和“已严格核对”等自述不作为正确证据。局部改善后保留未解决项，按影响与收益安排下一轮。
