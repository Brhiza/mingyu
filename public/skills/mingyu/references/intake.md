# 问题建模与资料采集规范（Intake & Verification）

在进行任何玄学推演或排盘前，必须先将用户的自然语言诉求转化为明确的问题模型，并核验时间与最小必要资料。严禁在资料关键要素缺失时替用户臆造时辰、经纬度或起课时间。

---

## 1. 建立内部问题卡（Question Card）

将用户输入的日常口吻整理为结构化问题卡，识别核心诉求本质：

| 字段 | 说明与取值范围 | 示例 |
| :--- | :--- | :--- |
| **主诉求（Core Issue）** | 用户最迫切需要得到解答的一个核心问题 | “今年能否顺利跳槽到新行业？” |
| **事项对象（Subject）** | 分析的主体：本人、伴侣、子女、父母、团队、特定项目、房屋、特定日期 | 个人职业发展与新岗位对接 |
| **任务目标（Goal Type）** | 认识命局潜能 / 把握周期趋势 / 短期成败抉择 / 双方互动博弈 / 时空方位布局 / 优选日期 / 象征性反思 | 短期选择判断 + 年度周期趋势 |
| **时间跨度（Time Horizon）** | 本命终身 / 10年大运 / 1-2年流年 / 本月流月 / 未来7-14天 / 指定关键时刻 | 本年度（未来6个月内） |
| **决策推进阶段（Stage）** | 未萌（动念萌芽） / 酝酿（准备方案） / 胶着（谈判推进中） / 突发（面临抉择） / 终局（复盘反思） | 酝酿向推进过渡期 |
| **现实硬性约束（Constraints）** | 现有资金、家庭责任、合规法律、行业资质、地点跨度、身体状况等 | 无法接受异地搬迁，需保证现金流不中断 |
| **用户预设术数（Requested System）** | 用户明确要求使用的术式（如“用紫微看”、“摇六爻”） | 未指定（或指定“看八字”） |
| **资料完整度（Data Completeness）** | 完整（年月日时地点俱备） / 部分缺失（缺时辰/地点） / 仅有自然问题 / 存在时空矛盾 | 阳历年月日俱备，时辰仅知“傍晚” |

---

## 2. 最小必要资料分级清单

不同术数对资料的严谨度要求不同。遵循**“按需索取、不强求无关信息、缺位诚实降级”**原则：

### A. 命理类（八字、紫微斗数、星盘、七政四余、奇门终身局）
- **完整资料**：出生年、月、日、时（精确到分钟更佳）、性别、出生地点（省市区或经纬度，用于真太阳时校正）、历法类型（公历/农历）。
- **缺时辰（时柱未知）处理**：
  - **八字**：仅排年月日三柱（前六字），重点分析日主五行生克、月令气候调候、年日支合冲刑害、大运早中期节律。**严禁**推断时支子女宫、晚年终局归宿或依赖时支的细幼神煞。
  - **紫微斗数**：**必须停止排盘**或明确告知无法安立十二宫命身宫（紫微安命依赖生月与生时）。严禁随意盲猜一个时辰排盘。
  - **西洋星盘 / 七政四余**：上升点（ASC）、天顶（MC）及后天十二宫失效；仅能做太阳月亮大致相位与星体本命星座分析，不可定位分宫吉凶。
  - **奇门终身局**：时干遁甲与值使门依赖生时，缺时辰不可起终身盘。
- **缺地点经纬度处理**：
  - 若用户未提供出生地点，使用法定民用时（如北京时间 UTC+8）排盘，但在结论中说明：“未做真太阳时经度时差校正，若出生于中国东西部边缘地区（如新疆、西藏、黑龙江）或海外，时辰分界点前后可能存在柱位偏差”。

### B. 占问类（六爻、梅花易数、奇门遁甲时家、大六壬、金口诀、小六壬）
- **最小资料**：明确的具体事情、起课占问时刻（带时区 ISO 8601），或明确的起卦参数（如梅花数字、金口诀地分、六爻铜钱投掷记录）。
- **注意**：占卜**不需要**求测者的生辰八字（除六爻取世应年命克应做辅证时可选）；不可把一事一占强行索要出生年月日时。
- **问题清晰度**：一事一占，不可把“我的婚姻如何、事业如何、健康如何”三个大问题塞入同一卦课中。

### C. 择日与风水类
- **黄历择日**：事项类别（结婚/搬家/开业/动土等）、起止日期范围（建议 15~31 天）、主事参与人资料（至少出生年份与生肖，用于规避冲煞岁破）。
- **住宅风水**：房屋坐山朝向度数（实测罗盘度数）、建造或入住年代（确定三元九运）、入户大门朝向、家庭主要成员生年（确定命卦）。缺坐向度数时不可断精确玄空九宫飞星。

### D. 象征性反思类（塔罗、雷诺曼、灵签）
- **最小资料**：当下聚焦的反思议题、抽取的牌阵/签文结果。无需出生时辰。

## 3. 时间口径与时区冲突消歧

1. **历史夏令时核验**：
   - 中国曾在 1986 年至 1991 年实行夏令时（每年 4 月中旬至 9 月中旬拨快 1 小时）。若用户出生在此时段，需确认提供的是钟表时间还是已校正时间，并适时应用夏令时回调。
2. **时区与地点冲突**：
   - 若用户输入“1995-06-15 14:30:00+08:00，出生地：美国纽约”，出现显式时区（+08:00）与实际地理时区（纽约 EDT/EST）冲突：
   - **严禁静默任选其一**！必须先指出时区冲突：“您提供的出生地点为纽约（属于西五区/西四区），但时间格式带有东八区标识。请确认该时刻为纽约当地钟表时间，还是换算后的北京时间”。
3. **真太阳时与早晚子时**：
   - 子时跨日（23:00~01:00）：23:00~24:00 属于晚子时（夜子时），00:00~01:00 属于早子时。在八字中晚子时日柱是否换日依流派口径明确说明；在小六壬与紫微中晚子时日期到零点才换日。
