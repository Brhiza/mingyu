# 各术数专属解读语法与取用逻辑规范（Interpretation Syntax）

每种术数都拥有其传承千百年的独特推理逻辑、符号系统与取用规则。严禁使用一套空洞套话或万能模板强套所有术数，必须遵循各术数自洽的推理语法。

---

## 1. 八字命理学（Four Pillars / Bazi）

**标准推演语法链条**：
`日主天干` → `月令真机与提纲五行` → `四柱干支气势配置与十神显微` → `日主强弱旺衰与调候用神` → `原局刑冲合会合化破害` → `大运十年基准换运` → `流年太岁引动与岁运交织` → `具体现实事项映射`

**关键规范**：
- **五行数量严禁等同强弱**：八字不是数金木水火土的个数！三个水生在未月可能极干，一个木生在寅卯月当令而旺。五行必须结合月令节气深浅与藏干司令判断旺衰。
- **流派取向明确**：
  - *子平派（ziping）*：以月令格局为体，取清纯用神与相神，重视调候与天干通根透出；
  - *盲派（mangpai）*：以宾主体用为纲，重宫位划分、禄印护身、地支穿绝刑害作功效率与开库闭库；
  - *新派（xinpai）*：重百神论、用神反断与干支作用先后次序。
- **神煞仅作副证**：天乙贵人、驿马、桃花、天月二德等神煞必须附着于十神用神之上方有实效，不可脱离五行生克单独断吉凶。

## 2. 紫微斗数（Ziwei Dou Shu）

**标准推演语法链条**：
`命宫与身宫星曜基准` → `命迁子田财官三方四正格局配置` → `十四正曜庙旺利陷与辅佐煞曜` → `生年四化（禄权科忌）先天落宫定盘` → `大限十年命迁官财移步换位` → `流年流月流日太岁引动与叠宫飞星` → `四化交错（生年、大限、流年）吉凶共振`

**关键规范**：
- **层级严禁混乱**：本命盘代表先天格局与潜质，大限代表十年环境际遇，流年流月代表当期触发事件。不可将流年天干引发的化忌当成本命格局破败。
- **流派理路并蓄**：
  - *三合派（sanhe）*：重十二宫位格局、吉凶主曜辅曜汇合、三方四正对拱；
  - *飞星派（feixing）*：重宫位天干所化出的禄权科忌飞入飞出链路，看气数因果牵引；
  - *四化派（sihua）*：重以生年四化为先天太极点，观天地人三才盘交感。

## 3. 西洋占星学（Western Astrology）

**标准推演语法链条**：
`四轴（ASC/DSC/MC/IC）与恒星时分宫` → `日月水金火本命星体星座与落宫` → `主要硬相位与软相位几何关系（合/冲/刑/拱/六合）` → `外行星守护星与互溶互照` → `行运星体过境（Transits）` → `次限（Secondary Progressions）与太阳弧（Solar Arc）` → `逆行停滞与精确度数峰值窗口`

**关键规范**：
- **外行星慢星定基调，内行星快星定引动**：天王星、海王星、冥王星、土星、木星形成长期背景压力或转型主题；火星、金星、水星、太阳与新月满月触发具体事件。
- **逆行与三次过境主轴**：对同一本命点的顺行进入、逆行复现、顺行脱离，必须归纳为同一成长周期的三幕剧，而非三次互不相关的事件。

## 4. 奇门遁甲（Qimen Dunjia）

**A. 奇门终身局（Lifetime Chart）**：
- **核心轴**：以求测者出生时刻起局，年干为父母社会名位与根基，日干为自身性情与行藏，时干为晚景后代与成果产出；值符九星定先天性情，值使八门定行事归宿；
- **行限大运**：支持四柱分限法（0-16年柱初限、17-32月柱中前限、33-48日柱中后限、49-80时柱末限）、洛书九宫巡行法或符使卦轨大运法（六爻周流至八爻归魂晚晴），结合流年太岁入局动静叠合。

**B. 时家奇门占断（Hourly Qimen）**：
- **核心轴**：地盘为体、天盘为用；九星司天时、八门司人事、八神司冥冥护持、九宫司地利方位；
- **用神与主客**：依问事选定用神（事业看开门、求财看生门、婚恋看乙庚与六合、官非看景门与惊门）；明确主客之道（急从神兮缓从门，动者为客、静者为主）。

## 5. 六爻预测学（Liu Yao / Wen Wang Ba Gua）

**标准推演语法链条**：
`起卦时刻日辰月建` → `定本卦与变卦` → `排定安世应与六亲（父母/兄弟/子孙/妻财/官鬼）` → `根据所问之事确立用神` → `考察月建生克与日辰生克（旺相休囚死、日冲、月破）` → `分析动爻发动、动变生克、化退化进、化回头克` → `原神、忌神、仇神力量博弈` → `空亡、墓绝、反吟、伏吟与六兽辅断` → `推演成败与精确定应期`

**关键规范**：
- 用神为主轴，不可脱离用神妄谈吉凶；世爻为己，应爻为彼或事体；
- 动爻为变之枢纽，变爻只能生克发动之爻，不能反跨宫生克静爻；
- 应期推断遵循“静而逢值逢冲、动而逢合逢值、太旺逢墓逢克、衰绝逢生逢旺、空而逢冲逢出”。

## 6. 梅花易数、小六壬、金口诀与大六壬

- **梅花易数**：以体卦为主、用卦为事，看体用生克（用生体大吉、体生用耗泄、体克用费力可得、用克体大凶、体用比和百事顺遂）；参考互卦看中间波折，变卦看最终归宿；卦气旺相休囚定吉凶权重。
- **小六壬**：农历月、日、时三宫顺数推演，严格以**时宫**为最终决疑主证，月宫日宫仅为推进轨迹记录；通行六宫（大安身不动吉、留连事难成拖延、速喜立见吉庆、赤口官事防盗凶、小吉行人立至喜、空亡事无成谋空）。
- **金口诀**：人元、贵神、将神、地分四位一览无余；以阴阳相克论“五动”（妻动、财动、鬼动、贼动、兄弟动），见生克而定干谒、财帛、疾厄。
- **大六壬**：东方人事预测之巅，四课奠定彼我主客基础（贼克、比用、涉害等九宗门取初传）；三传（初传发端、中传移易、末传归结）展示事件发生、演变到结局的全生命周期；十二天将（贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后）描摹具体人事神情。

## 7. 住宅风水学（Residential Fengshui）

- **八宅派（Bazhai）**：以房屋坐山定宅卦（东四宅/西四宅），以居者生年定命卦；大游年九星（生化延绝祸六五天）考量宅命相合、大门方位、主卧床位与灶位吉凶。
- **玄空飞星（Xuankong Feixing）**：以三元九运立极，结合精准罗盘坐向度数排布山盘、向盘与运盘；考量“到山到向”、“上山下水”、“双星到向”、“双星到山”四大局型；察九星旺生衰死煞气机流转。
- **合参要则**：八宅定人宅适配之常理，玄空定时空运转之盛衰；两者并重且绝不替代现实通风、采光、噪音、消防与房屋建筑结构安全。

## 8. 象征探索与古典神示（Tarot, Lenormand, Divination Slips）

- **塔罗牌（Tarot）**：遵循 78 张韦特体系结构，大阿卡纳揭示灵魂觉察与宏观生命课题，小阿卡纳（权杖/圣杯/宝剑/星币）展现现实行动、情感、思维与物质细节；牌位关系决定意象投射，正逆位反映能量的顺畅或阻滞。
- **雷诺曼（Lenormand）**：36 张日常具象符码，极重相邻合读与指示牌（28男/29女）距离方位；十字阵与大桌牌阵展现现实人际网络与事态线索，不做虚妄哲理空谈。
- **三山国王灵签**：古典纯正民间神示，以签诗原诗为宗，结合历史典故（如苏秦背剑、刘备求贤）提供德性反思与行事启迪，绝不附会现代伪造吉凶分数。
