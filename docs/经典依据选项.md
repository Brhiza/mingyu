# 经典依据选项

本目录收录可按术数方法选用的少量传统依据。代码中的 `summary` 是规则转述，不是原文引文；`application` 说明该条依据适用于什么盘面和占事。原文链接只保存在结构化记录与本文，不进入生成给 AI 的提示词。

经典依据默认关闭。开启后按所用方法选择，每种方法至多两条；八字紫微合盘各取一条，单次选取最多三条。输出正文仅包含书名、篇章、规则转述和适用条件。

当前支持八字、紫微斗数、八字紫微合盘、六爻、梅花易数、金口诀、奇门遁甲、大六壬、黄历择日、小六壬、太乙、五运六气、皇极经世、八宅、阳宅修造居住和七政四余。`huangji`、`wuyun`、`qimen-lifetime`、`bazi-compatibility`、`ziwei-compatibility` 分别指向对应的经典依据目录。

## 使用方式

- 页面提示词和 AI 工具栏：勾选“附经典依据”，切换时沿用本次盘面。
- MCP 与公开 API 的对应提示词入口：传入 `includeClassics: true`；省略或传 `false` 保持原有输出。
- 开启后，三种 `responseMode` 均返回 `classicalReferences`，包含书名、篇章、规则转述、适用条件和原文链接；合参分册只返回当前册体系的依据。

## 已核验条目

条目依据以下可读原典转录核对内容与篇章定位。

### 八字

- **《子平真诠评注》卷三·论用神成败救应**：以月令为格局用神的纲领，再结合四柱干支辨成败与救应。适用于已由四柱排盘确认月令格局的命盘。原文短句：“用神专寻月令，以四柱配之”。[原文](https://www.ncc.com.tw/fate/paleo/bg/bg_033.htm)
- **《滴天髓》天干论**：分论十干体性，并依各干所临季节与五行关系说明作用。适用于按具体天干条目考察原局，依条文所列季节、干支与五行条件解读。[原文](https://zh.wikisource.org/zh-hans/%E6%BB%B4%E5%A4%A9%E9%AB%93/02)

### 紫微斗数

- **《紫微斗数全书》卷一·太微赋**：星曜各有所属，庙旺、失度、同宫和生克制化须合全盘关系推论。原文短句：“星之分野，各有所属”。[原文](https://zh.wikisource.org/zh-hans/%E7%B4%AB%E5%BE%AE%E6%96%97%E6%95%B8%E5%85%A8%E6%9B%B8/%E5%8D%B7%E4%B8%80)
- **《紫微斗数全书》卷一·斗数发微论**：四正、三方、对照与合照共同参与判断，星曜入垣、失地影响格局。适用于宫位和星曜安置完整的命盘。
- **八字紫微合盘**：分别取《子平真诠评注》月令格局原则与《紫微斗数全书》太微赋全盘原则各一条；两类盘面分别按各自条件分析。

### 六爻

- **《增删卜易》卷一·八宫图第三**：按占问事项选取用神，依八宫装列世应、六亲与五行。适用于纳甲六爻盘。[原文](https://zh.wikisource.org/zh-hans/%E5%A2%9E%E5%88%AA%E5%8D%9C%E6%98%93)
- **《增删卜易》卷一·八宫图第三及用神诸例**：合看旬空、月破、日月生克、冲刑、动爻与变爻判断用神。适用于盘面已有纳甲、世应、六亲和动变信息的卦。原文短句：“旬空、月破，生克、冲刑”。[原文](https://zh.wikisource.org/zh-hans/%E5%A2%9E%E5%88%AA%E5%8D%9C%E6%98%93)

### 梅花易数

- **《梅花易数》卷一·为人占、自己占、物卦起例**：可依言语、人物、身物、服色、外物、年月日时或书写资料起卦；后天物卦以物取上卦、方位取下卦并加时取动爻。原文短句：“以物为上卦，方位为下卦”。[卷一原文](https://zh.wikisource.org/zh-hans/%E6%A2%85%E8%8A%B1%E6%98%93%E6%95%B8/%E5%8D%B7%E4%B8%80)
- **《梅花易数》卷二·体用总诀**：体卦为主、用卦为事，结合互卦、变卦及卦气生克察事势。适用于已确定体用和互变的梅花卦。[卷二原文](https://zh.wikisource.org/wiki/%E6%A2%85%E8%8A%B1%E6%98%93%E6%95%B8/%E5%8D%B7%E4%BA%8C)

### 金口诀

- **《六壬神课金口诀古本》卷之上·消息妙论、入式歌解**：课式由地分、月将、贵神、人元四位组成；以入式歌、五动、格局、神煞、空亡月破和四位生克合断。适用于按该书四位法排出的金口诀课。原文短句：“五动爻观其大意”。[卷之上转录](https://simplelits.com/books/classical/classical-08347-%E5%85%AD%E5%A3%AC%E7%A5%9E%E8%AF%BE%E9%87%91%E5%8F%A3%E8%AF%80/3)

这份可读转录的底本信息不完整，书目页面将作者、年代和底本列为不详；因此条目只用书名与篇章，不附会孙膑等作者传说。

### 奇门遁甲

- **《遁甲演义》卷一·烟波钓叟赋**：依节气与阴阳遁定局，在九宫布列三奇六仪并结合九星、八门等盘层取象。适用于起局时间、阴阳遁和九宫盘层已经明确的奇门盘。[原文](https://www.shidianguji.com/book/SK1616/chapter/1l9lop9pxu33o)

### 大六壬

- **《六壬大全》天将总论**：以天地盘布贵神，天将随盘运转；断吉凶合看天盘乘神与日干、所加地盘神之间的生克旺衰。适用于已给出天地盘、日辰、四课三传与天将的大六壬盘。[原文](https://www.shidianguji.com/book/SK1599/chapter/1k1lqkhebd2cy)

### 黄历择日

- **《钦定协纪辨方书》卷四·义例二·建除十二神**：建除十二日从月建起建、依十二辰顺行；书中比较不同家法，认为宜忌须参合事项、阴阳五行和诸神煞。适用于按年、月、日择事的通书语境。[原文](https://zh.wikisource.org/zh-hans/%E6%AC%BD%E5%AE%9A%E5%8D%94%E7%B4%80%E8%BE%A8%E6%96%B9%E6%9B%B8_%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29/%E5%8D%B704)

### 小六壬

- **《多能鄙事》卷八·小六壬课时**：本篇明载“月下起日，日上起时”，并列大安、留连、速喜、赤口、小吉、空亡的月日起宫递推。适用于按本篇所述计数法立成的六宫课，解读时对应本次盘面实际采用的计数口径与宫序。[原文](https://www.shidianguji.com/zh/book/CADAL02097181/chapter/1lco8m1j7ucyw)

该书页面署名明刘基编，但这不能证明小六壬术法起源于刘基，也不能推出此篇计数法等同于现代各支流算法。

### 太乙神数

- **《太乙金镜式经》推五将所主法**：以五将和主客关系组织太乙式中的观察框架；原篇主要以军旅胜负为占例。适用于已提供太乙局式、五将和主客位置的盘面。[篇章原文](https://www.shidianguji.com/zh/book/SK1615/chapter/1l9lir7w2l5ay)

### 五运六气

- **《黄帝内经素问》天元纪大论**：以岁干配五运，并以司天、在泉和左右间气构成年度气化框架。适用于明确岁干、岁支与运气历法的年度运气盘。[篇章原文](https://www.shidianguji.com/book/DZ1018/chapter/1k85j5ct44fmu)

### 皇极经世

- **《皇极经世书》（四库全书本）卷一上·观物篇一·以元经会一**：以元、会、运、世及年月日时的层级记数展示时间坐标。适用于已经按本书纪数口径给出的盘面，须对应所用起算纪元。[原文](https://zh.wikisource.org/zh-hans/%E7%9A%87%E6%A5%B5%E7%B6%93%E4%B8%96%E6%9B%B8_%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29/%E5%8D%B701%E4%B8%8A)

本篇所见的周期坐标不等同于现代公历换算方案；公历映射需由具体排盘规则另行核对。

### 八宅

- **《阳宅大全》八宅四书卷首卷二·八宅四**：以八方为地、八卦为宫、九星为星，依宫星与宅方五行生克和游年布星判断宅位。适用于坐向、八方宫位和游年九星已明确的八宅盘。[原文](https://www.shidianguji.com/zh/book/CADAL02094260/chapter/1laxwz09awkz6)

### 阳宅居住布局

- **《阳宅三要》卷一·阳宅三要论**：以门、主、灶为阳宅三要，合看三者所在宫方的五行生克及相生、比和关系。适用于已明确大门、主房、灶所在方位及宅主命卦的居宅盘。[篇章转录](https://fs.qqqs.org/fssj/308.html)

### 七政四余

- **《张果星宗》卷十一·续论七政四余分布宜忌及入格真伪**：按星曜宫度、昼夜、月相与星体生克、先后、会合条件辨析格局。适用于具备相应宫度、行度、昼夜及会合信息的星命盘。[卷十一转录](https://guolaoxing.com/archives/4926)

此卷通过术数文献整理网站转录，未据此认定“张果”历史作者身份。《星命溯源》四库本也指出相关作者传说与星宗源流尚有区别：[《星命溯源》](https://zh.wikisource.org/zh-hans/%E6%98%9F%E5%91%BD%E6%BA%AF%E6%BA%90_%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29)。
