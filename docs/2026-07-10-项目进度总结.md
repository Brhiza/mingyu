# 命语项目进度总结（2026-07-10）

## 一、项目定位

命语（mingyu）= 算命 / 占卜 / 择日的**提示词生成**工具。核心算法包 `mingyu-core` 独立发布 npm，应用层 React + Vite + MCP Server。定位「精准提示词输出」，非专业排盘软件——用户把提示词发给其他 AI 做实际计算。

线上：[aov.cc](https://aov.cc) ｜ 公开 API ｜ MCP Server ｜ 公开 skill。
