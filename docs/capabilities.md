# 完整能力与算法边界

本页说明命语可以计算哪些资料，以及各能力当前采用的边界。网页、提示词、公开 API 和 MCP 默认使用精简输出；审计、研究或二次计算时才需要完整证据。

## 统一输出

- 排盘结果按 `input`、`calendar`、`chart`、`timing`、`summary`、`evidence` 和 `warnings` 提供统一视图，底层各术式仍保留自己的专业结构。
- 公开 API 与排盘类 MCP 默认使用 `detailMode: "compact"`，保留核心盘面并省略提示词、完整证据链和重复计算过程；显式传 `detailMode: "full"` 才返回完整结构。
- 提示词接口默认只返回可直接交给 AI 的自包含任务书，不要求调用方清理工程字段和审计资料。
- 八字岁运按精确交运时刻裁剪可选范围，时间边界提供结构化资料；标准十二时辰模式不会额外补造“晚子时”。
- 紫微入口已纳入 Vite 与 Webpack 浏览器契约测试，应用无需绕过核心包直接调用 `iztro`。

## 命理排盘与合盘

### 八字

提供四柱、十神、藏干、纳音、神煞、大运、流年、旺衰、格局、用神和调候分析。神煞默认采用问真整理口径并返回常用范围，也可显式切换传统兼容口径或请求全部项目。岁运按精确交运边界筛选，提示词只保留所选层级的有效触发资料。

八字双盘可计算日主、日支、四柱交叉关系、双向十神、喜忌覆盖与结构化证据，适用于婚恋、合作、友情、亲子、父母和兄弟关系。

### 紫微斗数

以 `iztro` 原生能力输出十二宫、星曜、亮度、四化、三方四正及本命、大限、流年、流月、流日、流时，并随结果披露实际安星、闰月、分年、运限月份、小限年龄和晚子时口径。三合派、飞星派、四化派选项只改变解读侧重点，不改底层安星。

固定版本传统目录现登记 87 项，其中 55 条具备原文与可复算条件；32 项因原文含糊或依赖运限，只登记边界而不伪造命中。原 84 条未校勘项目规则继续停用，目录外格局不作判断。

### 西方占星

提供太阳、月亮、上升星座、宫位、十大行星、逆行提示和主要相位。本命、行运和双盘相位会输出角度偏差、容许度位置与紧密等级，不把归一化值包装成事件概率、匹配率或吉凶百分比。

流年、流月和流日会扫描周期内动态点，列出精准行运相位、天象互相位、停逆、换座、换宫、朔望与交食；流年还保留太阳返照、次限和太阳弧。太阳返照采用粗定位加二分细化，并返回黄经残差、搜索过程和精度边界。

### 七政四余

输出七政四余十一星、命身十二宫、宿度庙旺、吊照、月相与出生时刻光照。七政、罗睺、计都和月孛采用现代天文位置，二十八宿使用 28 颗真实距星在目标日期的黄经划界；紫炁保留《七政算内篇》古法均速模型，并明确区分位置精度层级。

### 合盘与关系分析

支持八字、紫微和西方占星双方盘面结构化提示词。关系主题包括婚恋、合作、友情、亲子、父母和兄弟等；静态双盘资料不会被包装成缺乏统一依据的匹配总分。

## 占卜

### 六爻

采用京房八宫法排盘，包含纳甲、六亲、六神、世应、动变、空亡、日破、月破、化进神、化退神和六亲持世等信息。回头冲、动变五行关系与化空可同时保留。

输出用神候选、原神忌神仇神作用链，以及逐爻月日、空破墓、动变支持与反证，不生成吉凶总分。

### 梅花易数

支持时间起卦、数字起卦和随机起卦，包含体用生克、四时旺衰、64 卦完整爻辞，以及主卦、互卦、变卦逐阶段体用推进与支持、限制证据。

### 小六壬与金口诀

小六壬保留可核验的通行时间起课，并提供适合临时小事的快速判断。金口诀按地分、将神、贵神、人元四位一体生成课盘与结构化证据，支持直接指定地分，也可按时间、数字或随机方式取地分。

### 奇门遁甲

时家奇门默认采用转盘法，可通过 API 参数请求飞盘法；定局默认拆补法，也可请求置闰法。盘面包含天地人神四盘、值符值使、格局标签、节令背景、复合格局与宫位洞察。

结果会给出值符、值使、日干、时干对应的用神宫候选，逐宫保留门星神干、空亡、马星、格局、宫间作用、反证及方位与时间触发条件，不用数字评分替代判断。

### 大六壬

提供天盘、四课、三传、月将、贵人、旬空、课体与问题范围选择，并输出四课取传依据、初传发用、三传推进及逐传旺衰空亡的支持与限制。

### 塔罗与雷诺曼

塔罗包含 78 张牌，支持单牌、时间流、爱情、事业、选择等牌阵。逐牌保留牌位、正逆位、关键词、元素、牌阶、牌序和解释限制，不输出能量分数或成功率。

雷诺曼支持常用关系、选择与大型牌阵，并保留牌序、位置和组合关系。

### 三山国王灵签

收录源自广东潮汕三山国王祖庙的 92 签体系。每签保留签号、签题与签诗原文，提示词只列本次签谱资料并直接围绕问题解读。

不同庙本可能存在签序、题名和字句差异，解读以本次签文为准。项目作者来自揭西，这套签文的整理也希望帮助传统民间文化继续被看见和使用。

### 自定起卦时间

六爻、梅花易数、奇门遁甲和大六壬可在网页端选择当前时间或自定北京时间；公开 API、MCP Server 和 Skill 使用 `customDate` 传入带时区的 ISO 8601 时间。

## 择日、风水与其他术数

### 黄历择日

支持搬家入宅、订婚结婚、开业启动、签约合作、出行赴任、就医手术、考试学习、安葬修坟、修造动土等事项。

结果按 `tyme4ts` 原始宜忌、参与人刑冲破害、时辰与现实限制，分成可用、条件和慎用候选，不设置或包装吉凶总分。

### 住宅风水

统一入口会分层计算八宅人宅适配与玄空飞星宅运结构，再输出合参要点与建议，不生成综合吉凶总分。

只提供普通出生年月日和性别，或只填写大门向屋内度数/山向，也可以使用；建造或起运年为可选项。八宅负责命卦宅卦与四吉四凶，玄空负责下卦的运盘、山盘、向盘与到山到向，并在边界敏感时保留候选山向。底层仍可分别调用八宅与玄空。

### 太乙神数

支持年、月、日、时四计，输出太乙、文昌、始击、计神、主客定算、将参与十六神盘，并提供由计算链、主证、辅证、反证和方法限制组成的结构化证据。年计采用积年与阳遁七十二局立成；月、日、时计按现代历法定位复现通行四计，时计按冬夏至分阴阳遁。

月、日、时计不等同于逐项复原古籍章月、月法、日法、气应与小余等历法常数；结果会保留这一口径边界，不把简式交叉资料写成古籍真值。

### 皇极经世

支持按北京时间起年月日时盘。盘面先返回元会运世、会内统卦、运卦、六十年统卦、十年卦和值年卦，再以冬至换年及二十四节气的三百六十日坐标继续推演月经卦、旬纬卦、日卦和时经卦。年度研究仍可只传公元年，自定义纪元场景仍可使用指定纪元的元会运世周期换算。

### 五运六气

按公历年输出中运太过不及、司天在泉、五步主客运、六步主客气、五音太少、气运相临和符会结构，并保留交司日期的古籍口径边界。

## 公共历法与传统地基

### 干支、五行、方位和神煞

- 干支：统一提供十天干、十二地支、六十甲子、六旬旬首、纳音、藏干、阴阳五行、合冲刑害破、三合三会。
- 五行：统一提供生克、月令旺相休囚死和天干地支结构出现统计，可选计入藏干。
- 方位：把罗盘度数换算为二十四山坐向、后天八卦与分界状态。
- 神煞：严格核验完整四柱，逐项返回空亡、驿马、桃花等规则的起法、目标地支、命中柱位、来源声明和解释限制。

核心包入口为 `mingyu-core/foundation`；线上入口为 `/foundation/capabilities`、`/foundation/ganzhi`、`/foundation/wuxing`、`/foundation/direction` 和 `/foundation/shensha`。

### 真太阳时与历史时区

真太阳时由 `mingyu-core/calendar` 统一提供，线上可使用 `/calendar/true-solar-time`。中国省市区和经度数据随核心包提供。

历法层可以把当地钟表时间换算为 UTC、`JD(UTC)`、近似 `JD(UT)` 与 `JD(TT)`，同时返回 ΔT 模型、估算等级和精度限制。它支持用 IANA 时区解析历史夏令时、回拨歧义和跳时缺口，并统一处理中国 1986—1991 年历史夏令时。

### 月相、太阳光照和节气

- 月相：由日月地心黄经差输出月相角、最小距角、照明近似、盈亏、八相、近似月龄及前后朔弦望时刻。
- 太阳光照：按日期、经纬度和历史时区输出太阳高度、真北方位角、视太阳正午、日出日落及民用、航海、天文曙暮光。
- 二十四节气：采用 `tyme4ts` 历表，并按每隔 15° 太阳视黄经定义，使用 Meeus/NOAA 低阶公式独立求根核验。

输出会保留模型、残差与精度限制，不因显示到秒而宣称观测级精度，也不会把月相或天文数据自动解释为吉凶。

## 通用解释边界

- 时间型术式不机械换算固定天数、周数或百分比，只输出盘内相对节奏、触发条件与适用边界。
- 不用综合分数替代不同证据之间的关系，也不把术式结果包装成确定概率。
- 命理、占卜和玄学结果仅供参考与娱乐学习，不替代医疗、法律、投资或心理咨询等专业建议。
