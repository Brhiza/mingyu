# 周易经文来源

`packages/core/src/classics/zhouyi.ts` 中的卦辞、彖辞、爻辞和小象按六十四卦逐页核对维基文库《周易》原典页面。页面地址使用以下规则，卦名替换为对应短名：

<https://zh.wikisource.org/zh-hans/周易/乾>

本次核对日期为 2026-09-11。乾、坤及其余各卦页面均直接查看“易经”“彖曰”“象曰”段落；没有采用合并的小象转录页作为唯一底本。页面中的简体字形由维基文库页面转换提供，括号内校记未写入应用字段。

页面短名按项目卦序逐一对应；遁卦沿用维基文库页面的传统字形地址：<https://zh.wikisource.org/zh-hans/周易/遯>。卦名、卦序和卦宫仍以项目字典为准。

代码字段保留项目既有格式：卦辞和爻辞去掉段末句号以便与现有提示词拼接，保留原文内部标点；彖辞和小象保留“彖曰：”“象曰：”标记。卦序、卦名、上下卦和卦宫沿用原字典，不从来源页面重新推导。

维基文库页面内容按 CC BY-SA 4.0 条款提供；《周易》古典原文本身属于公版。本文件只记录原典核对来源，来源说明不会写入发送给在线 AI 的提示词。
