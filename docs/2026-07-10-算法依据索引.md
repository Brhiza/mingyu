## 紫炁单一模型

项目只保留《七政算内篇》紫炁古法均速，不提供月孛对冲、月球近地点、真远地点或 MOIRA 历元等可切换模型。

| 项目         | 当前采用值                                                         |
| ------------ | ------------------------------------------------------------------ |
| 行向         | 顺行                                                               |
| 周期         | 10227.1792 日，约二十八年一周天                                    |
| 古法速度     | 二十八日一度；每日三分五十七秒一四二九                             |
| 至后策       | 1256.5224 日                                                       |
| 现代复原历元 | 1995-12-31T00:00:00Z，回归黄经 237.038993°                         |
| 计算式       | `回归黄经 = normalize(237.038993 + 距历元日数 × 360 / 10227.1792)` |

主要证据：

- 《七政算内篇》“四余星第七·紫气”直接给出顺行、周积、至后策、度率和日行分。
- 《高丽史》卷五十二复载“每日顺行，三分五十七秒……二十八日行一度”。
- 《革象新书》卷三说明紫气每日所行均平、起于闰法、约二十八年周天，并与月孛分列。
- 《古今律历考》卷五十八复载同一立成，并指出末位收舍造成的约 0.0308 日周积差；为保持模型同源，项目仍采用《七政算内篇》原载周积，同时公开该校勘边界。
- MIT 开源项目 [PlanetCalendar](https://github.com/fftkrr/PlanetCalendar/blob/3a9f317c0e6c16294c9feb0da4f233d12dd7a29e/cal_calculation.c) 提供从古法立元到现代历元的可复现换算。

对照但不采用：MOIRA / FINASTRO 虽使用相同周期，却采用 1975-03-13 16:00 UTC、230.5° 的历元；该历元与《七政算内篇》现代复原值相差约 99.11°，未提供足以取代古籍立元的推导。Horosa 参考压缩包另有把紫气映射为瑞士星历真远地点的实现，也不符合古籍“均平顺行、二十八年周天”，因此不并入计算。

## 已移除体系

- 铁板神数：后续核验确认公开项目没有可验证的完整考刻流程与完整条文实现，原有少量示例属于占位内容，因此核心包、前端、公开 API 和 MCP 已全部移除；在找到可核验完整资料前不恢复。

## 审查与回归证据

- 新增体系与公共地基回归：`tests/core-new-systems.test.ts`
- 八字、紫微、奇门、六爻等既有回归：`tests/*.test.ts` 与 `packages/core/src/**/*.test.ts`
- 逐项算法规则与古籍依据：对应算法源码的文件头、规则注释和结构化来源字段。
- 提示词真实生成样本：运行 `pnpm prompt:audit` 后写入 `.local/reports/prompt-audit/`。

内部审查过程、阶段总结和大体积生成样本保存在 `.local/`，不纳入版本控制。后续若取得更可靠版本或原表，应先在算法源码、公开依据索引或测试中写明版本、页码或公开链接，再修改算法与回归测试；不能只凭二手口诀覆盖现有实现。
