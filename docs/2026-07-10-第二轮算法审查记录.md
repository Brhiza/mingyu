# 命语第二轮算法审查记录（2026-07-10）

## 审查目标

本轮不以“增加更多名称”为目标，而是检查底层函数是否会接受不存在的输入、静默返回伪结果，或用简化公式冒充完整算法。对无法完整核验的范围，宁可停止暴露，不继续输出看似精确的结果。

## 太乙重构的精度边界

当前年家太乙采用以下口径：

- 积年为 `10153917 + 公元年`，余数 0 作第 72 局。
- 太乙、文昌（主目）、始击（客目）按阳遁七十二局逐局表取值。
- 主算、客算按立成表取值，不再用宫数顺逆累加代替。
- 太乙八宫数为 `1乾、2午、3艮、4卯、6酉、7坤、8子、9巽`；对应宫卦名分别为乾、离、艮、震、兑、坤、坎、巽，两者不再混用。
- 计神按阳遁岁支逆布取十六宫位置。
- 十六宫间神返回完整 16 位，不再裁成 12 条。

2004 年甲申回归结果：积年 10155921，阳遁第 33 局，太乙在艮（第 3 宫），文昌在午（第 2 宫），始击在艮（第 3 宫），主算 24，客算 3。

月计、日计、时计各有独立积月、积日、积时和阴阳遁起局规则。旧实现只改变 `scope` 标题，实际仍以公元年份起局，因此已从核心包、前端、公开 API 和 MCP 同步停止暴露。后续只有在四类积算和阴阳遁都完成可复现校核后才会恢复。

## 后续审查原则

1. 只有天干、地支各自合法，不代表它们的组合属于六十甲子。
2. API 和 MCP 不能依赖核心包的默认回落来“容错”，非法枚举和业务矛盾应在边界层返回明确错误。
3. 随机算法除了可复现性，还必须检查分布和独立性；“每次都有数值”不等于算法正确。
4. 逐局表、历元、周期和边界口径必须附固定来源或可复现推导，不用无来源的简化公式补空。
5. 资料不完整时停止暴露对应能力，不以“实验性”名义对外返回伪精确结果。
