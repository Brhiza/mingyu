# Changelog

## 0.1.23 (2026-07-28)

### 新增与修复

- 重新审查小六壬规则：仅保留可复核的通行时间课和六宫歌诀，删除无可靠来源的数字/随机、流派、三宫现实阶段、五行旺衰、六亲神煞与固定应期扩展，并明确版本学和历法边界。
- 重新审查紫微格局来源：原 84 条项目规则缺少逐条版本、卷页、原文和独立例盘，已整体退役；从零恢复 18 条可在《紫微斗数全书》卷一、卷三固定版本直接核对且具备可复算条件的规则，并向核心结果、提示词、公开 API 与 MCP 输出来源和边界。未登记格局不作判断。
- 删除紫微提示词中由项目自行把命宫六合位命名为“暗合宫”的无来源扩展；来因宫仅保留 iztro 原始盘面标记。

- **太乙四计失败关闭**：只保留完成积年与阳遁七十二局立成校勘的年计；月、日、时计在节气时刻、章月、月法、日法、气应与小余历法链完成前明确拒绝。
- **恢复七政四余完整盘**：七政、罗睺、计都和月孛采用现代天文位置；二十八宿按SIMBAD距星J2000坐标、自行和目标日期黄道转换形成真实宿界；紫炁保留《七政算内篇》均速模型并明确标记精度层级。完整盘恢复十一星、命身十二宫、庙旺、吊照、月相、光照和结构化证据。
- **实现玄空兼向替卦**：按入中星本宫同元龙山取替星，五黄借实际山向，顺逆依所取山阴阳；支持明确指定替卦或按坐山度数自动触发，并输出替星过程和证据边界。
- **西洋星盘固定真实出生瞬间**：真太阳时只作为传统时间参考证据，不再替换现代星历使用的民用出生时间；相位返回取消最强 12 条截断，保留阈值内全部结果。
- **统一出生档案保留传统时辰**：`BirthProfile` 支持直接提供 `timeIndex`，八字、紫微等时辰级算法不再被迫填写精确分钟；真太阳时、星盘和七政四余严格要求精准时分与所需地点资料。
- **出生时间口径结构化证据**：标准化结果新增输入模式、精度、代表时刻边界、历法换算、真太阳时状态、时辰映射、证据汇总与解释限制；不生成候选时辰、敏感性结果或缺时柱命盘。
- **岁运补全三合三会证据**：八字岁运触发证据新增跨原局、大运与流年层级的完整三合、三会结构核验，只记录补全成局事实，不直接声称成化或吉凶应期。
- **生肖三会关系证据**：生肖流年新增 `meeting` 字段与三会固定关系表证据；两支同组只记为三会关系，不并入贵人、有利或风险关系，也不视为完整三会成局。
- **八字合化条件校正**：移除月令、透干、根气、清杂等任意百分制权重；天干按日干参与、紧贴、规定月令、克破与争合逐项核验，地支六合只记录相合及冲破，不再直接裁定为某五行成化。
- **紫微格局目录说明同步**：当前固定版本目录已扩充为 55 条可复算规则与 32 项不可唯一复算边界；同步核心、应用、MCP、公开 API 与技能文档，历史首批恢复 18 条的记录保持不变。
- **十神分布移除隐藏强弱阈值**：删除透干与藏干的 1/0.8/0.5/0.3 权重及“有力、偏重”裁定；改为直接输出透干数、藏支数和“缺位、仅藏、透出、透藏并见”状态。
- **梅花互卦角色校正**：依《梅花易数》卷三“体用互变之诀”，按原体所在上下卦正确区分体互与用互，并分别输出二者对原体的五行关系；证据层不再把体互、用互重新组成互卦内部体用，阶段推进、反证与旺衰触发同步采用原体主线。证据关系由主卦、互卦、变卦和动爻重算，不采信旧结果中的派生体用字段。
- **梅花坐端应兆边界**：依《占卜坐端之诀》单独登记观察中心、现场实际方位和真实兆象三项必要资料；当前输入不具备这些现场记录时明确返回资料不足，不以主互变卦方位、问题文字、设备位置或行政地名补造父母子女、身体病位、吉凶或应期。
- **梅花全卦克应候选与情境边界**：依《占卜克应之诀》逐项登记主卦用卦、体互、用互、变卦用卦对原体的生克方向及制化回指；事项类型、是否确需刻期、自然期限、材质、远近、时间尺度、数克或理克口径及应验方向未齐时不猜事项、不换算日期。
- **梅花万物耳目外应资料边界**：依《万物赋》单独登记现场耳闻目见、成卦前后、观察时序、对象类别与实际状态、当时关注对象及事项关联七项必要资料；当前入口缺少这些记录时明确返回资料不足，不从问题、卦象、设备感知、历史回忆或事后挑选补造外应和例断。
- **梅花饮食专项适用与版本资料边界**：依《饮食篇》分开登记具体饮食或宴请之占、判断对象、己人客酒食物专项角色、动静原始记录、宴食时间及主客关系五项必要资料；当前入口缺少专项上下文且底本句读未完成校勘时，不从问题关键词、普通体用或卦内动爻补造具体饮食与宾主结论。
- **梅花观物专项适用、取主与版本资料边界**：依《观物玄妙歌诀》分开登记观物或射覆适用范围、待辨对象状态和所需属性三项情境，并保留通行底本艮离段落未闭合、本篇未独立交代体用互变取主顺序两项规则缺口；与后续占物规则合校前不从问题关键词或通用盘面补造具体物件属性。
- **梅花诸事响应专项情境与高风险边界**：依《诸事响应歌》登记事项类别、具体对象、精确判断目标、现实状态与角色关系等必要情境，保留同一体用关系跨事项含义冲突及“比和凶则有救星”版本未闭合；资料不足时不套用天气、人事、婚育、疾病、公讼等专项歌诀，也不生成胎儿性别、诊断用药、事故原因、诉讼胜负或确定财务婚姻结论。
- **梅花诸卦反对性情卦画与版本边界**：逐项复算主卦、互卦、变卦的综卦与错卦，保存通行《杂卦传》六十四卦抽象卦义，并单独登记当前《梅花易数》底本的错名、漏名和句义移位；不得据刚柔忧乐灾困等词推断人物性格、动机、现实事件或确定吉凶。
- **梅花占物类例规则层级与版本边界**：完整留档《占物类例》第 935 至 938 行，区分动爻爻辞、八卦象、体卦刚柔形体、用卦功用、体用生克与用变互色数层级，并登记“困于株林”“体生方圆曲直”“用变互卦”、互卦数量取值及后续取主范围等未决问题；专项情境和版本口径未齐时不生成具体物件或精确数量。
- **梅花物数为体取主、阴阳爻与版本边界**：完整留档《物数为体诀》第 939 至 941 行，登记多卦取体、乾坤刚柔、阴阳爻多少及五六爻动等候选规则，并保留卦象统计范围、“非金非石”、生旺判准、“不入五行物”、阴阳爻统计与后续变卦取主等未决问题；不据规则目录生成具体物性或动静结论。
- **梅花观物变爻取象与版本边界**：完整留档《观物看变爻为主》第 942 至 943 行，登记乾卦初、二、三爻对应的变后经卦、完整变卦与原文物象候选，并保留标题正文异文、句读、变卦名义、例证覆盖及多种取主口径优先顺序等未决问题；不据三个例子生成主导卦、主导五行或具体物件结论。
- **梅花观物克应与现场资料边界**：完整留档《观物克应法》第 944 至 945 行，将成卦未决时偶见圆物、负土、刚健与柔腐仅登记为现场候选，并复用耳目外应的七项原始资料要求；保留“物之成败”、体卦克应合参及多项偶见物取舍等未决问题，不据问题文字、设备感知或通用盘面生成待辨物属性与成败结论。
- **梅花观物趣时候选与版本边界**：完整留档《观物趣时诀》第 946 至 947 行，将春震离、夏震、秋兑、冬坤只登记为花、有声之物、毁折成器之物与无用土物候选；保留四时分界、得卦层级、震离组合句义与例证覆盖等未决问题，不据通用盘面生成具体物件、有声、毁折、成器、材质或用途结论。
- **六爻动变条件并见**：依《增删卜易》六冲、回头生克与旬空各章，新增完整 `changeRelations`，分别保存可并见的回头冲、五行关系与化空；旧 `changeRelation` 保持兼容。
