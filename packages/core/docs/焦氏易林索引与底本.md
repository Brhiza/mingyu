# 焦氏易林索引与底本

`mingyu-core/classics` 中的焦氏易林查询使用固定修订版数据集。该数据集对照两份转录底本：Wikisource 四库全书本和 Kanripo `KR3g0029` 的 WYG 四卷本。查询按六十四卦固定顺序建立本卦到之卦的 64×64 索引，共 4096 条。

## 固定来源

- Wikisource 四库全书本：《易林（四库全书本）》卷一至卷四，页面模板为 `https://zh.wikisource.org/wiki/易林_(四庫全書本)/卷{1..4}`。本次核对记录的修订号依次为 `784348`、`784351`、`784354`、`784357`。
- Kanripo：`KR3g0029`，WYG 四卷 `001` 至 `004`，页面模板为 `https://www.kanripo.org/ed/KR3g0029/WYG/{001..004}`。

正式数据文件为 `packages/core/src/classics/data/yilin-w20-03-pair-index.json`、`yilin-w20-03-gap-report.json` 和 `yilin-w20-03-confirmed-mappings.json`。入口同时返回两个底本的原始标签、卷次、页码或转录行号、原文标记和文本摘要，便于复核来源。

## 差异边界

索引覆盖 4096 个卦对。缺字与校勘记录共 120 项：69 项维基文库单侧字形记录（涉及 16 个不同 SKchar 编号）、46 项两份转录可对齐但字形尚待辨认的记录、3 项字形标记数量差异，以及两份转录各一项卦名顺序差异（艮→小畜，底本原标“小過”）。这些记录不等于全部文字差异；查询仅在两份清理后的正文完全相同且没有校勘记录时标为文字一致。底本异文和未定字形分别保留。

卷尾转录尾注只在公开 `text` 字段中做确定性的卷尾清理，并以 `textNormalization: "fixed-volume-footer"` 标明；其余原文和标记保持底本数据。固定索引是文献查询，不承担起卦、随机取卦或根据卦名推断爻变。

## 公开入口

- 核心包：`queryYilinEntry(baseHexagram, targetHexagram, source?)`、`getYilinEntry(...)`、`getYilinEditionMetadata()`、`getYilinIndexStats()`。
- REST：`POST /api/v1/classics/yilin`，请求字段为 `baseHexagram`、`targetHexagram` 和可选 `source`。
- MCP：`classics_yilin_query`，参数与 REST 相同。
- 网页：`/classics/yilin`，用于按固定卦序查询和对读两个底本。
