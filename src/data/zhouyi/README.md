# 周易经文数据

`texts.json` 从原项目 `packages/core/src/classics/zhouyi.ts` 转录，按六十四卦保留卦辞、彖辞、大象、六爻爻辞、小象，以及乾坤用辞。每条附项目简称与对应维基文库页面的固定修订号；项目经文采用简体字形，并去掉卦辞、爻辞的段末句号。原数据没有《文言》，本数据也未添加。

校对来源、逐卦修订链接、校对日期及范围见 [来源.md](./来源.md)。转录以维基文库《周易》各页贡献者为来源，页面内容按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 提供；古典原文本身属于公版。卦序、卦名、卦宫沿用项目资料，未独立完成异文校勘。接口结果与引用经文的提示词均包含出处及许可。
