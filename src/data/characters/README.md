# 字库资料

字形、读音、笔画、字义及字书原文来自旧项目 `packages/core/src/name-number` 的生成资料和异体字修订；此处是 V2 的独立数据快照，不在运行时引用旧项目。基于旧接口逐字展开，将 5011 个实际查询字形映射到 3813 条不同字目；相同字目共享资料。原文缺失保留缺失，不借用其他字的条目。

`index.json` 是紧凑字目和字形索引，`search-order.json` 固定原字库筛选顺序。字义与原文按字目编号对 32 取余分别分片；姓名学三才、数理和姓氏读音资料供后续姓名功能使用。`version.json` 为索引、顺序和全部字义与原文分片的 SHA-256，更新数据后运行 `pnpm data:character-version`；构建会校验版本，资源路径包含版本，避免新旧字库分片混用。原项目内容及传统文献归属、字形映射、笔画和释义尚需独立校勘；与旧实现一致不等于事实已经核验。
