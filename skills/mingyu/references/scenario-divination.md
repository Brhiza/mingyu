# 占卜问事、择日与风水场景指南

> 适用场景：具体事件吉凶与走势占问（六爻、奇门、大六壬、梅花、金口诀、小六壬、塔罗、雷诺曼、灵签）、黄历择日与住宅风水评估。
> 起卦范围、时间口径与经文边界见 [事件占问与起局范围](event-divination.md)。

## 一、事件占问（一事一占）

### 前置确认
- ⛔ **必须确认**：具体所问事项（最好明确主语与时间范围）、用户指定的占法（未指定时按 [方法路由](routing.md) 推荐一种，不擅自同时起多卦）、以及是否已有线下摇卦/抽牌记录。
- 💬 **默认可跳过**：无特殊要求时采用当前起卦时刻与默认牌阵/规则，向用户说明默认值并允许“都用默认”。
- **铁律**：随机起卦、抽牌、求签**只执行一次**；后续围绕同一件事的追问必须使用 `reprompt` / `/api/prompt` 传回原结果或 `repromptToken`，绝不重新起卦或抽牌。

### 分术数解读要点
- **六爻 (`liuyao`)**：先定世应与用神候选，再结合引擎返回的月建日辰、动变、暗动/日破/旬空及 `evidence` 证据层说明成败条件；如启用 `includeClassics`，如实引用返回的《周易》经文。
- **奇门遁甲 (`qimen`)**：先固定问事主体与用神宫位，优先引用引擎已识别的经典格局（`classic-patterns`）、组合象意（`pattern-combos`）、证据层与应期（`ying-qi`），同时注明所选盘式（转盘/飞盘）与时间口径（北京/地方时/真太阳时）。
- **大六壬 (`liuren`) / 金口诀 (`jinkoujue`)**：先固定问事主体与取课方式，紧扣四课、三传、天将与神煞或四位生克关系说明事态起承转合。
- **梅花易数 (`meihua`)**：分清主卦、互卦、变卦、动爻与体用生克，结合起卦方式（时间/数字/字数/物象）说明当前态势与转折点。
- **塔罗 (`tarot`) / 雷诺曼 (`lenormand`) / 灵签 (`ssgw`, `zhuge`)**：严格依据实际牌序、牌位、正逆位、组合关系或签诗原文解读，明确区分“原文/象征”与“现实推断”，不把牌象当成对他人内心或现实结果的确定证明。

### 应期（何时有结果）原则
- 仅引用工具实际给出的应期依据或盘面时间线索；若盘面未给出明确应期条件，必须如实说明“当前依据不足以精确到具体日期”，改为提示关键观察节点或需满足的现实条件。

## 二、黄历择日 (`almanac`)

- ⛔ **必须确认**：要办的具体事项（如搬家、动土、嫁娶、开业、出行）、候选日期范围，以及（如用户希望结合个人避冲）关键参与人的出生资料。
- **执行要点**：
  - 长日期范围必须检查 `data.page.nextOffset` 并续页收集完整，不可把第一页当作整个时间段的全部候选。
  - 解读时列明每条候选日期的宜忌、民俗神煞（如十恶大败、三娘煞、杨公忌）与参与人冲合说明；月相背景不作为初筛依据。
  - 若范围内无完全理想日期，说明折中方案与各日期的取舍条件。

---

## 三、住宅风水 (`bazhai` / `xuankong` / `residential`)

- ⛔ **必须确认**：
  - 仅看命卦与宅向：需要房屋坐向（二十四山或度数）及居住者出生年份/性别（`bazhai`）。
  - 看玄空飞星或综合住宅：还需明确房屋建造/入伙年份（确定元运），以及是否涉及兼向替卦（`xuankong` / `residential`）。
- **执行要点**：
  - 坐向测量存在误差边界时，保留工具返回的误差候选并分别说明，不静默择一。
  - 综合评估（`residential`）按已有资料分别说明八宅与玄空的对应要点，**不捏造综合吉凶总分**。
  - 明确说明线上排盘不含室外形峦、采光通风与实地格局勘测，建议结合实际居住舒适度综合权衡。
