# 事件占问与起局范围

周易经文 `zhouyi` 可按卦序或卦名查询，也可用 `search` 检索并按 `nextOffset` 续页；结果保留维基文库固定修订、署名、许可及转录说明。六爻和梅花的 `prompt.includeClassics` 会依据实际卦与动爻引用经文，不自行编造爻位；当前不提供《文言》，也不声称已完成异文校勘。

大六壬 `liuren` 可使用 `liuren: { "timeStandard": "true-solar", "longitude": 116.4 }`，必须由用户提供实际经度；日时按真太阳时钟表，年月、节气与月将按实际起课时刻。未提供经度时默认北京时间，不自行猜测经度。

六爻 `liuyao` 可使用 `range` 提供最长两小时、整秒、起点含终点不含的起卦时间范围；该范围不与 `divinationTime` 同时使用，不能把出生时间自动当作起卦时间。所有分支复用一次卦象；时间起卦采用整个范围起点取数，需向用户说明只是代表时刻。追问传回完整原结果，不重新起卦。

六爻默认 `time` 是用起卦时间戳确定性模拟三钱，不是实摇或按年月日时取数；不能把模拟过程说成传统人工起卦。`coins` 区分程序模拟和调用方提交的三钱结果，`yarrow` 区分程序模拟和调用方提交的蓍草分堆；调用方提供的记录不证明线下来源。

大六壬可使用 `range: { "start": "带时区的起点", "end": "带时区的终点" }`；起点包含、终点不含，须为整秒且不超过两小时，不与 `divinationTime` 同时使用。分别解释返回的全部分支，分支起点只是代表时刻，不是确定占时；追问沿用完整范围结果。

金口诀 `jinkoujue` 同样支持真太阳时与最长两小时范围：真太阳时在 `jinkoujue` 中设置 `timeStandard: "true-solar"` 和用户提供的 `longitude`。范围随机起课只选一次地分，全部分支和追问复用；不要为每个分支重新抽取。

奇门时局 `qimen` 可使用 `qimen: { "timeStandard": "civil", "timeZoneId": "America/New_York" }` 指定 IANA 地方时区，或用 `timezone` 指定固定 UTC 偏移小时；两者不可同时提供。地方时区影响日时，节气和年月仍按实际瞬时。最长两小时范围遇夏令时偏移变化会分段；不自行推测用户所在地。真太阳时仍另用 `timeStandard: "true-solar"` 和用户提供的经度。

太乙 `taiyi` 的月、日、时计支持真太阳时与最长两小时范围；在 `taiyi` 中设置 `scope`、`timeStandard: "true-solar"` 与用户提供的 `longitude`。节气、年月与时计阴阳遁依据实际时刻。年计仅输入年份，不使用范围或真太阳时；范围分支起点只是代表时刻。

皇极经世的 `huangji.mode: "datetime"` 支持真太阳时及最长两小时范围；真太阳时须由用户提供 `longitude`。时段按四小时钟表划分，节气、皇极年和皇极日序按实际时刻。范围代替 `huangji.date`，须分别解读各分支；其他皇极模式不接受范围。
# 随机选择占法

仅在用户明确要求随机选术数时使用 `random-divination`。可在 `methods` 限定候选，但必须均已启用；服务返回 `data.selectedMethod` 和 `data.result`，提示词在外层 `prompt.text`。向用户说明实际选中的术数，后续追问以 `random-divination` 和完整外层结果调用 `reprompt`，不要再次选择或起盘。需要调整该术数提示词选项时，先查询实际选中方法的 schema。太乙默认按北京时间所在年起年计，塔罗和雷诺曼默认单张。
