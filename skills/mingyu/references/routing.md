# 按用户任务选择工具

先遵循用户指定的术数；没有指定时，依据主体、问题和需要的时间范围推荐一个适合的入口。下表是选工具的起点，不保证用户所连的服务启用了所有工具；以 MCP 工具目录或 HTTP 方法目录为准。先看所选工具的 schema，不用示例值代替用户资料。

| 用户想做什么 | V2 方法 | 使用边界 |
| --- | --- | --- |
| 八字本命、指定时点岁运或流月时间线 | `bazi` | 精确出生加性别可用 `timelineYear` 查询一个立春年；时间范围和时辰未知不计算精确岁运。完整最终格局与用神尚未完成。 |
| 两人八字关系 | `bazi-synastry` | 不选候选时比较全部组合；变化事实按 `comparisonPage` 和 `nextOffset` 续页，选定双方候选后可查看逐项双盘。 |
| 紫微本命或运限 | `ziwei` | 选择非本命运限需提供参考时刻。 |
| 紫微双盘 | `ziwei-synastry` | 双方出生候选的变化事实需要分页；不含完整双人运限。 |
| 八字与紫微合参 | `bazi-ziwei` | 两种盘共用出生资料，不确定时按真实时间交集比较。 |
| 同一人的多体系综合命录 | `minglu` | 以八字为基础，按实际资料聚合紫微、西洋星盘与八宅命卦，输出分节 Markdown 与提示词；不生成旧版评分。 |
| 日运、月运、年运（通用或个人定制） | `fortune` | 支持 daily/monthly/yearly 三种周期；省略出生资料为通用流时运势，提供个人档案则融合八字喜忌、紫微四化与星盘行运输出定制化趋势概览与报告提示词。 |
| 西洋星盘本命或推运 | `astrolabe` | 需要出生时间、经纬度及时区；返照可另指定地点，周期事件按游标分页。 |
| 西洋双人合盘 | `astrolabe-synastry` | 当前是双人本命比较，不含组合盘及双盘动态运限。 |
| 西洋星盘不确定出生范围 | `astrolabe-range` | 秒级分页；出生分页与可选的周期分页分别续取。 |
| 七政四余本命、流曜或行限 | `qizheng` | 需要出生时刻、经纬度及时区；完整专业证据仍在迁移。 |
| 七政不确定出生范围 | `qizheng-range` | 秒级分页；不要把某个候选当成确定出生盘。 |
| 奇门终身局 | `qimen-lifetime` | 出生范围逐候选秒读取；阶段模型依资料选择。 |
| 依据当前或指定时刻起即时盘 | `instant` | 可选八字、紫微、合参、西洋星盘或七政；即时盘不是出生盘。 |
| 用户明确要求随机选择占法 | `random-divination` | 仅从已启用的候选中选择，返回已选术数与完整盘面；追问保存并传回外层结果。 |
| 六爻事件起卦 | `liuyao` | 可按时间、爻值、三钱或蓍草起卦；原卦追问不能重新起卦。 |
| 梅花易数事件起卦 | `meihua` | 支持时间、数字、声音、文字、方位物象及随机起卦。 |
| 奇门事件、方位或时局 | `qimen` | 支持时、日、月、年盘和不同时间口径。 |
| 大六壬事件起课 | `liuren` | 按时刻起课；可保留起课时间范围分支。 |
| 金口诀事件起课 | `jinkoujue` | 可按时间、地分、数字或随机地分起课。 |
| 小六壬快速问事 | `xiaoliuren` | 通过时间及所选规则起课。 |
| 塔罗问事 | `tarot` | 用户指定牌阵，可随机抽牌或录入已抽牌及正逆位。 |
| 雷诺曼问事 | `lenormand` | 用户指定牌阵，可随机抽牌或录入已抽牌。 |
| 三山国王灵签 | `ssgw` | 可随机求签或指定已有签号。 |
| 诸葛神数 | `zhuge` | 支持汉字三字、三数字取签（第 1–384 签）与五枚铜钱起卦（三十二课）。 |
| 八宅命卦和宅向 | `bazhai` | 不含玄空飞星或实地形峦。 |
| 玄空飞星宅盘 | `xuankong` | 需建造时间和坐向；替卦须核定兼向。 |
| 居者与住宅综合比较 | `residential` | 按已有资料组合八宅和玄空，不生成综合吉凶总分。 |
| 黄历与候选日期 | `almanac` | 基础择日预览；长范围可用 `page` 分页，按 `data.page.nextOffset` 续取，不能把单页当全范围；提示词可选日期或完整依据。月相背景不参与初筛。 |
| 五运六气年度资料 | `wuyun-liuqi` | 年度模型，不提供个人诊疗判断。 |
| 太乙年月日时盘 | `taiyi` | 年计与月日时计所需资料不同。 |
| 皇极经世周期或资料表 | `huangji-jingshi` | 按 `mode` 选择值年、年月日时、自定义历元、六日逐爻或资料表。 |
| 四柱反推可能出生范围 | `bazi-reverse` | 需要完整四柱和搜索年份，结果是候选而非确定时刻。 |
| 分析现有姓名 | `chinese-name` | 可结合出生资料或用户提供的五行；条件模型不等于最终喜用。 |
| 姓氏起名 | `chinese-naming` | 按提供的姓氏和偏好生成候选，不猜测辈分或实际读音。 |
| 分析号码民俗取象 | `number-energy` | 需要用户提供号码；不用于姓名分析或起名。 |
| 查汉字字形、释义或筛字 | `character-query` | 字库缺字和缺原文需明确说明；筛选按 `nextOffset` 续页。 |
| 查询周易卦爻辞或检索原文 | `zhouyi` | 查卦或原文检索；检索须按 `nextOffset` 续页，尚不含《文言》。 |
| 节气、月相、真太阳时、时间尺度或日出日落 | `calendar` | 按 `calendar.kind` 选一种资料；时间尺度等包含近似模型。 |

复合问题可拆为不同主体或时间范围的子问题，先说明各方法的作用；未经用户同意，不应为了凑齐多个方法重复随机抽牌或起卦。对同一已生成盘面的新问题，使用 `reprompt` 或 `/api/prompt` 并传完整原结果；分页只覆盖实际保留的页。资料不全时询问会改变计算的缺项，或使用工具明确支持的不确定候选；不自行推测性别、出生时刻、经纬度、时区、投掷记录或牌面。
