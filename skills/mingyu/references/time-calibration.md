# 考时与出生时间校准

> 适用场景：用户不确定出生时辰、只记得大致时段（如上午/凌晨）、出生时刻临近时辰或节气交界（前后 30 分钟内）、涉及 23:00 晚子时换日、历史夏令时或真太阳时偏差，或仅有四柱需要反推可能出生范围。

## 核心原则

- **绝不静默选盘**：工具返回多个候选分支时，必须保留候选及其成立条件，不能挑一个最顺眼的候选当作确定盘。
- **充分利用引擎候选能力**：命语 V2 的 `bazi`、`ziwei`、`bazi-ziwei`、`astrolabe-range`、`qizheng-range`、`bazi-reverse` 与 `calendar`（真太阳时/节气）均原生支持边界拆分与候选展开，先用工具算清差异，再结合用户现实经历核对。

## 标准校准流程

| 步骤 | 标记 | 动作与目标 | 对应工具 / 产物 |
| --- | --- | --- | --- |
| 1. 收集已知事实 | ⛔ | 确认已知出生日期（公/农历）、大致时段或候补时辰、出生地点（用于真太阳时与时区）、性别，以及 2–3 件用户确认记得年份的人生大事（如升学/毕业、重大换工作、结婚/分手、购房/搬迁、重大健康或家庭变故）。存在历史夏令时歧义时先向用户确认钟表口径。 | 已知事实与验证事件清单 |
| 2. 展开候选与边界 | — | 用对应工具展开候选分支：八字/紫微合参优先用 `bazi-ziwei`（自动取两盘真实时间交集）；单体系用 `bazi` 或 `ziwei` 的未知时辰/时间范围模式；仅有四柱时先用 `bazi-reverse` 反推 `birthRange`；需核对交节或真太阳时偏移时用 `calendar`。 | 候选集与受影响范围（影响时柱、日柱还是年月柱/大运） |
| 3. 识别稳定项与差异项 | — | 对比各候选的共同点（如年/月/日柱不变的部分）与差异点（如时柱、紫微命宫/十二宫分布、大运起运或节气切换）。仅交节差异重点核对八字大运与岁运；时辰差异同时核对八字时柱与紫微命盘宫位。 | 稳定字段与时敏差异清单 |
| 4. 逐候选对照现实大事 | — | 用引擎对各候选分别查看对应年份的大运/流年或运限证据（如命宫/夫妻宫/事业宫/财帛宫变动、冲合引动），与用户提供的 2–3 件大事逐一核对，记录吻合项、矛盾项与无明确信号项。 | 逐候选吻合证据表 |
| 5. 给出裁决与确认 | ⛔ | 按下方「证据覆盖分级」汇报结论、关键盘面依据与未验证项；即使出现唯一或优势候选，也须请用户确认后再进入后续深度解读。 | 校时结论报告 |

## 边界与降级处理

| 边界场景 | 处理方式 |
| --- | --- |
| 出生时间距时辰交界或节气交界 ≤ 30 分钟 | 先按用户输入排盘，但必须旁注提醒存在真太阳时/钟表误差风险，建议结合大事核对，不把该盘当成无争议确定盘。 |
| 宝宝或青少年（缺乏可验证人生大事） | 跳过大事考时，直接按提供的钟表/真太阳时排盘；起名场景直接使用 `chinese-naming` 的出生范围或明确五行策略。 |
| 用户已确认精确出生证明且无交界/时制争议 | 尊重用户确认，不强行要求考时。 |
| 可验证人生大事不足 3 件，或完全没有 | 明确标明“考时精度不足 / 证据不足”，不强行定案，提供下方降级选项。 |
| 候选时辰超过 5 个（如完全不知上午还是下午） | 先请用户通过记忆线索（白天/夜晚、父母回忆、是否天亮等）缩小范围，或仅就各候选共有的稳定信息（如八字前三柱）先作有限说明。 |
| 八字与紫微校准指向不同候选 | 如实并列两侧证据与分歧点，不强行合并或覆盖其中一侧。 |

## 输出结构

1. **结论**：明确给出分级结果：
   - **唯一候选**：结构排除或大事核对后仅剩一盘吻合；
   - **优势候选**：吻合度明显领先（写出各候选吻合项对比）；
   - **并列候选**：多个候选各有吻合，尚难分出高下；
   - **证据不足**：缺少足够验证事件或信号不明显。
2. **盘面依据**：列出各候选在对应大事年份的实际柱位/宫位、流年/运限引动及引擎返回的证据，区分吻合项与矛盾项。
3. **不确定项**：说明哪些事件未出现明确对应信号，以及对结论的影响。
4. **后续选项**（非唯一确实时提供）：
   - 补充 1–2 件其他重要人生变动及年份继续校准；
   - 暂以当前最可能候选看趋势，并在结论中显式标注「未定盘/条件性时辰」；
   - 仅分析所有候选共有的稳定部分（明确排除时辰敏感项）。
