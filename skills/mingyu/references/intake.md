# 资料输入与真实性核验规范（Intake & Verification Specification）

## 一、各门术数信息采集要素（全门类）

根据所选术数门类，仅采集推演所需的最小必要参数（客观直接，无需客套虚饰）：

1. **先天命理类（八字 / 紫微斗数 / 星盘 / 七政四余 / 奇门终身局）**：
   - 历法类型：公历（阳历）或农历（阴历），闰月需确认；
   - 出生时间：具体年月日与出生时分（若时辰不详，八字仅排前三柱，紫微/终身局暂停起盘）；
   - 出生地点：省份与城市区县（用于计算真太阳时经度时差与历史夏令时换算）；
   - 性别：男（乾造）或女（坤造），决定大运顺逆与起运交运岁数排布；
   - 关注诉求：所问具体方向（事业、财运、婚恋、健康或宏观格局）。
2. **事态占问类（六爻 / 奇门时家 / 大六壬 / 金口诀 / 梅花易数 / 小六壬）**：
   - 明确唯一事项：一事一占，禁止多事杂问；
   - 占问时间：当下精确时刻（公历年月日时分）；
   - 术数特有起卦参数（可选）：六爻铜钱摇卦记录、梅花报数/物象、金口诀指定地分、大六壬月将；
   - *红线：占卜具体事项严禁强索生辰八字替代当刻卦象！*
3. **双方合盘类（八字合婚 / 紫微合盘 / 西占双盘）**：
   - 双方完整出生资料（年月日时分、出生地点、性别）；
   - 双方现实关系状态（已婚、恋人、商务合伙考察等）。
4. **时空择吉与环境风水（黄历择日 / 住宅风水合参）**：
   - 黄历择日：具体事项类别（嫁娶、移徙、开市、动土等）、候选起止日期范围（建议15~30天）、主事参与人生年生肖；
   - 住宅风水：房屋坐山朝向度数（罗盘实测度数）、建造或入住运年（确定三元九运）、居住人生年生肖。
5. **姓名数理与传统签谱（汉字姓名分析 / 三山国王灵签）**：
   - 姓名数理：姓氏与名字汉字原文，若需考查补益则附出生生辰；
   - 灵签求签：心中默想所求之事，获取签号与签诗原文。

## 二、资料缺失与边界处理原则

1. **缺时辰（时柱未知）处理**：
   - **八字**：仅排年月日三柱（前六字），重点分析日主五行生克、月令气候调候、年日支合冲刑害、大运早中期节律。**严禁**推断时支子女宫、晚年终局归宿或依赖时支的细幼神煞。
   - **紫微斗数**：**必须停止排盘**或明确告知无法安立十二宫命身宫（紫微安命依赖生月与生时）。严禁随意盲猜一个时辰排盘。
   - **西洋星盘 / 七政四余**：上升点（ASC）、天顶（MC）及后天十二宫失效；仅能做太阳月亮大致相位与星体本命星座分析，不可定位分宫吉凶。
   - **奇门终身局**：时干遁甲与值使门依赖生时，缺时辰不可起终身盘。
2. **缺地点经纬度处理**：
   - 若用户未提供出生地点，使用法定民用时（如北京时间 UTC+8）排盘，但在结论中说明：“未做真太阳时经度时差校正，若出生于中国东西部边缘地区（如新疆、西藏、黑龙江）或海外，时辰分界点前后可能存在柱位偏差”。
3. **历史夏令时与时区冲突消歧**：
   - 中国曾于 1986 年至 1991 年实行夏令时（每年 4 月中旬至 9 月中旬拨快 1 小时）。若用户出生于此时段，需确认提供的是钟表时间还是已校正时间，并在调用时正确传递夏令时参数。
