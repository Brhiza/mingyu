# 出生盘、双盘与出生范围

紫微六层运限的 `mutagenPlacements` 给出化星在本命盘及该运限宫序中的实际位置；出生不确定时分别读取对应候选。八字紫微合参的时机主题提供大限和流年落点。不要将这些位置误称为运限十二宫逐宫飞化，也不据此虚构事件或精确应期。

紫微选择飞星口径和运限范围时，提示词可将本命宫干飞化按该运限宫名重新标注；它沿用本命宫干与化星，不是另起运限宫干，也不包含流曜或跨层飞化。出生未知时可用 `candidateIndex` 查看单个候选的映射。

首次计算调用对应方法，HTTP 请求为 `POST /api/calculate`，请求体 `{ "method": "方法名", "input": { ... } }`。按实际 schema 收集资料。独立紫微 `ziwei` 支持精确、指定民用时辰与未知时辰；指定运限需要 `referenceTime`。八字紫微合参 `bazi-ziwei` 共用出生资料，并按两盘真实时间交集保留不确定候选。独立紫微双盘 `ziwei-synastry` 可比较双方出生候选：不确定时不能把任一候选当作确定结果；变化证据按 `comparisonPage` 分页，用返回的 `nextOffset` 继续获取，候选组合数不代表概率。选定双方出生盘后，飞星口径可查看双方宫干化星在对方本命盘的定位；该定位不是自化，也没有计算运限。七政范围 `qizheng-range` 也必须按 `nextCursor` 续取；周期事件扫描比单盘更耗计算。独立西洋星盘 `astrolabe` 支持精确出生本命及 `flow.reference` 指定时点的行运、返照、次限和太阳弧；年、月、日按当地代表时点取样，并非整个周期。`options.includeAsteroids` 可启用四颗小行星。太阳返照默认按出生地，可用用户明确提供的 `flow.solarReturnLocation` 经纬度指定返照地；年、月、日参考时点仍按出生地时区。缺失的资料应向用户询问，或保留工具提供的不确定候选。

四柱反推 `bazi-reverse` 需要完整年、月、日、时柱和用户指定的公历 `startYear`、`endYear`。结果使用标准北京时间、节气月和 23 点换日；列出所有候选，勿自行选定出生范围。用户选择某候选后可将其 `birthRange` 原样用于八字、姓名分析或起名。八字范围不计算精确起运及岁运。历史夏令时和真太阳时反推暂不支持。

八字单盘的 `timelineYear` 可查询一个北京时间立春年至下一立春的流月时间线，须有精确出生秒和性别；与 `referenceTime` 单个时刻查询分别使用。按返回的半开区间区分流月及交运，不把整段结果当作流日、流时或现实事件。默认完整提示词包含时间线，其他范围仍可读取结构化结果。

2057 年 9 月新月接近午夜，当前历表与香港天文台预测的农历日期相差一天。若农历出生资料报此分歧，请用户核对出生记录并提供公历日期，不自行猜测；部分按公历推导农历的工具仍在补充差异提示，相关提示词中的历法限制必须保留。

八字本命神煞可计算 55 项常用查法，元辰需要性别；缺失时明确标为未计算。逐柱起例及三奇、拱禄整局依据见返回结果；羊刃兼取阴干。未知时辰各候选各自计算，不把其中某段当作确定出生时刻；八字双盘可分别提供双方性别以计算元辰；未提供者不计算且不推测；八字紫微合参使用所选交集候选的本命神煞。未知时辰的共同项与逐候选差异需要结合阅读。精确出生并提供性别和参考时刻时，39 项岁运神煞按真实本命起例；仅使用所选岁运层级，不将本命专属或整局规则套入。扩展神煞、不同查法和其他岁运神煞尚未迁移。

独立八字的旺衰、化气、曲直、从儿、从财优先和专旺及通用从格都是条件模型；按返回依据解释，不把支局成势或天干相合直接当作化气成立。普通月令取格及其成败仅按所列条件判断，已实现路线的排序不等于完整最终格局。未知出生时比较各候选，不把单个候选当成确定盘；完整格局成败和最终喜忌用神尚未完成。

八字的取用基础方向只反映旺衰与已选格局模型，不能称作最终用神或双方喜忌覆盖；调候、病药、具体作用和岁运须另核。

普通八字格局可返回调候规则候选、条件状态及资料缺口；调候条件层按权限与优先级处理冲突，区分具体天干和整五行，不应称作最终用神。

病药及通关结果是候选，需结合月令、根气与柱位核验；司权和土月疏泄只在当前有利集合内排序，不将候选当成最终喜忌或双方喜忌覆盖。

八字普通格局的已列制化路径核对透藏、根气、合绊和柱位；多段路径要求同一中间干承接。条件模型的成败和救应仅适用于返回的有限规则，不等于完整流派裁定。

独立西洋双盘可调用 `astrolabe-synastry`，两人均需精确出生时间和地点。返回双向落宫、主要跨盘相位和传统接纳互溶；注意 `counts.omittedAspects`，必要时提高 `maxAspects`（最多 200）。它不提供动态运限或组合盘。

独立西洋本命结果中的 `distributions` 按太阳至冥王星十大星体统计元素、模式与逆行，`patterns` 列出格局成员及必要相位证据；同座或同宫星群不要求每对星体合相。150° 梅花相已计入相位与上帝之指判定。

西洋周期事件使用 `astrolabe` 的 `flow.period`：提供带偏移的 `start`、`end`，读取返回的 `data.flow.period.page.nextCursor` 并保持其他输入一致续页，直到为 `null`。窗口是 UTC 半开区间，每页最多 7 日。月相与交食可能同时列出；交食是全球事件，不可推断当地可见。单页追问不包含其他页面。

西洋出生时间范围使用 `astrolabe-range`：逐秒分页并按 `data.range.nextCursor` 续取；本命每页最多 20 秒，带推运最多 2 秒。组合 `flow.period` 时出生页为 1 秒、`period.pageDays` 必须为 1；每个出生候选都会独立扫描当前周期页，事件时间范围保存在分支 `metrics`。出生分页完成后仍须检查分支首盘 `flow.period.page.nextCursor`，以其续取下一个周期页并从出生游标 0 重新收集。网页和 `pnpm astrolabe-range 输入.json [HTTP计算接口URL]` 每次只汇总一个周期页。分支首秒只代表一个候选，连续指标及其他分支均须保留。

七政或西洋出生范围的完整命令行收集结果可在网页导入，或分别用 `pnpm --silent qizheng-range --reprompt 结果.json '新问题'`、`pnpm --silent astrolabe-range --reprompt 结果.json '新问题'` 追问；命令会重新计算整个出生范围并核对盘面。完整收集结果不能直接作为单页结果提交 HTTP/MCP 的 `reprompt`；西洋周期事件仍只覆盖收集结果中的当前周期页。

七政 `prompt.includeStarMeanings: true` 可附十一曜取象参考；它是未经古籍原文校核的项目整理，需与实际盘面事实分开，不应当作原典引文。出生范围多分支只附一次。
