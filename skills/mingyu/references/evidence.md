# 事实分层与证据审计规范（Evidence & Fact Layering）

排盘推演的致命陷阱在于**“把推测当事实”**。本规范建立严密的五层证据体系，严格区分数据来源与推理层级。

---

## 1. 五层证据架构

```text
L1 资料事实（Raw Intake）
    │  用户输入的原始信息（出生年月日时分、地点、性别、所问事项）。未经任何算法加工。
    ▼
L2 计算事实（Calculated Facts）
    │  由天文与历法算法计算出的硬指标：真太阳时、四柱干支、节气交接点、星曜宫位度数、
    │  卦象变爻、九宫奇仪分布。此层具有唯一客观数学解。
    ▼
L3 传统依据（Classical Rules）
    │  古籍经典中可核对的判定规则：如“寅月甲木透出为建禄”、“离宫见景门为本宫伏吟”、
    │  “世爻临玄武主隐秘”。标明出处，不掺杂主观引申。
    ▼
L4 关系推断（Inferred Dynamics）
    │  依据 L3 规则对 L2 事实产生的相互作用推导：生克制化、刑冲破害、用神得力与否、
    │  主客动静得失。推论必须能追溯到具体的 L2 与 L3。
    ▼
L5 现实映射（Real-World Grounding）
       将 L4 的玄学推断具象化翻译为现代生活场景（职业决策、人际博弈、时机选择），
       给出具有建设性、可核验的行动建议。
```

---

## 2. 证据记录核心原则

1. **绝对隔离**：L1 事实严禁自动“修正”或擅自篡改；若发现 L1 与 L2 冲突（如生于纽约但带东八区偏移），必须作为待消歧项显式抛出。
2. **推论可溯**：L4 推论中的每一句话，必须由具体的 L2 计算事实与 L3 传统法则支撑，禁止凭空断言“此命大富”或“此卦大凶”。
3. **保留反证**：当命局或卦象中同时存在吉凶互见、多方制约的线索时，必须完整列出相互牵制的两组证据，绝不可为了迎合或恐吓用户而单向偏颇。
